# 📖 Gerador de Passagens Bíblicas

Um gerador de passagens e versículos bíblicos simples, leve e totalmente funcional, desenvolvido exclusivamente com **HTML5, CSS3 e JavaScript puro (Vanilla JS)** — **sem recurso a APIs externas ou bibliotecas de terceiros**.

## 🚀 Sobre o Projecto

O objectivo deste projecto é disponibilizar passagens e versículos bíblicos de forma rápida e offline/local, armazenando e manipulando os dados directamente do lado do cliente (client-side).

Por não depender de chamadas a APIs REST externas, a aplicação possui excelente desempenho, tempo de carregamento instantâneo e zero dependências de servidores de terceiros.

## ✨ Funcionalidades

* 🎲 **Geração de Versículos Aleatórios:** Apresenta uma nova passagem bíblica a cada clique.
* ⚡ **Desempenho Ultra-rápido:** Todo o conteúdo é processado localmente no navegador.
* 📶 **Funciona Offline:** Não requer conexão com a internet após o carregamento inicial.
* 📱 **Design Responsivo:** Adaptado para telemóveis, tablets e computadores.
* 🎨 **Interface Limpa e Intuitiva:** Foco total na leitura da Palavra.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização, layout (Flexbox/Grid) e animações suaves.
* **JavaScript (Vanilla JS):** Lógica para selecção e exibição dinâmica dos dados.
